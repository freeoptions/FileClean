# FileClean

FileClean 是一个面向 Windows 的重复图片/视频扫描工具，支持固定扫描目录、分组展示重复文件、批量勾选重复项，并将选中文件移动到系统回收站。

## 当前已实现

- 固定扫描目录，重启后仍会保留
- 支持常见图片格式
  - `.jpg` `.jpeg` `.png` `.webp` `.gif` `.bmp` `.tif` `.tiff` `.heic` `.heif` `.avif` `.svg`
- 支持常见视频格式
  - `.mp4` `.mov` `.mkv` `.avi` `.wmv` `.flv` `.webm` `.m4v` `.mpeg` `.mpg` `.ts` `.mts` `.m2ts` `.3gp` `.3g2` `.ogv`
- 固定目录扫描
- 结果按重复组展示
- 结果字段包含
  - 路径
  - 文件名
  - 大小
  - 预览
  - MD5
- 支持每组重复文件勾选
- 支持“勾选重复”快捷规则
  - 当前规则：全路径最短者保留，其余文件自动勾选
- 支持将勾选文件移动到 Windows 回收站

## 针对大图库的性能方案

面对 10 万级图片库时，不能直接对所有文件无脑计算完整 MD5，否则会非常慢。FileClean 现在采用的是分层筛选策略：

1. 先遍历目录，只读取文件基础信息
2. 先按文件大小分组
3. 只有大小相同的文件，才继续做快速指纹
4. 快速指纹也相同的文件，才继续计算完整 MD5
5. 完整 MD5 相同，才认定为重复文件

### 快速指纹是什么

快速指纹不是完整 MD5，它只是一个更轻量的预筛选步骤。

当前实现是：

- 对较小文件直接读取完整内容生成快速指纹
- 对较大文件只读取文件头部 128 KB 和尾部 128 KB，再结合文件大小生成快速指纹

这样做的好处是：

- 比直接算完整 MD5 快得多
- 能把绝大多数“大小相同但内容不同”的文件提前排除掉
- 只有少量高疑似候选才进入完整 MD5 阶段

## 关于“先看大小，再算 MD5”

你的理解是对的：

- 如果两个文件大小不一样，它们一定不是完全相同的文件
- 所以大小不同的文件，不需要再比 MD5
- 只有大小相同，才值得进入下一步比对

这是重复文件扫描里最基础、也最有效的一层优化。

## 为什么最终还要算完整 MD5

因为“大小相同”不代表“内容相同”，而“快速指纹相同”也不代表“100% 完全相同”。

所以为了保证结果准确，最后仍然要对最后一批候选文件计算完整 MD5。这样就兼顾了：

- 速度：前面两层尽量少读磁盘
- 准确：最后一层做完整确认

## 缓存优化

为了让第二次扫描更快，FileClean 还加入了哈希缓存：

- 如果文件路径、大小、修改时间都没变
- 下次扫描时就可以直接复用上一次的 MD5 结果

这对经常扫描同一批目录时会非常有帮助。
